# Projects

## Final projects

| Project | Pathway | Description |

| [Security Investigation Toolkit](../careers/soc-analyst.md#final-project-security-investigation-toolkit) | SOC Analyst | Read-only host triage: logins, connections, persistence locations, firewall, hashed report |
