# Module 3: Networking & Troubleshooting

**Days 11–15 · Intermediate**

You will read and interpret IP configuration, troubleshoot connectivity layer by layer, diagnose DNS failures, map ports to applications, and capture packets for analysis.

## Module outcomes

- Interpret addresses, subnets, gateways and routes on both platforms.
- Run a structured connectivity investigation: link → IP → gateway → DNS → port → application.
- Resolve and debug DNS records and caching.
- Identify which process owns a listening port or connection, and capture traffic safely.
