# Module 2: System Administration

**Days 6–10 · Beginner → Intermediate**

You will manage accounts, control access with Linux permissions and Windows NTFS ACLs, investigate and control processes and services, analyse disk usage, and install and update software safely.

## Module outcomes

- Create and manage local users and groups on both platforms following least-privilege principles.
- Read and change Linux permissions (numeric and symbolic) and Windows ACLs.
- Find and fix runaway processes and failed services.
- Investigate full disks and manage software inventories.
