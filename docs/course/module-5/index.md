# Module 5: Scripting & Automation

**Days 21–25 · Intermediate → Advanced**

You will turn commands into robust, reusable scripts: variables and input, decisions and loops, functions with parameters and error handling, structured data processing, and scheduled automation with logging.

## Module outcomes

- Write readable, validated Bash and PowerShell scripts that use safe defaults.
- Process text, CSV and JSON into structured reports.
- Package logic into reusable functions with proper error handling.
- Schedule automated health checks with cron/systemd timers and Task Scheduler.
