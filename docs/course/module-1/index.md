# Module 1: Command-Line Fundamentals

**Days 1–5 · Beginner**

You will learn what shells are, move around the filesystem, create and manage files safely, read and search text, find help for any command, and connect commands with pipelines. This is the foundation that every later module builds on.

## Module outcomes

- Operate Bash and PowerShell confidently and know which edition or shell you are in.
- Navigate and manage files and directories with absolute and relative paths, wildcards and recursion.
- Read, filter and search files and logs.
- Combine commands with pipelines, and understand text pipelines (Bash) versus object pipelines (PowerShell).
