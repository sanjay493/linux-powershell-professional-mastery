# Module 4: Security, Logs & Monitoring

**Days 16–20 · Intermediate → Advanced**

You will investigate system and security logs, detect suspicious authentication patterns, audit and configure firewalls safely, run security baseline checks, and investigate unexpected network activity.

## Module outcomes

- Query the systemd journal, `/var/log` and Windows Event Logs efficiently.
- Detect failed and suspicious logins with Linux auth logs and Windows Security event IDs.
- Review and change firewall rules safely, with backups and rollback.
- Audit privileges, permissions and Defender status, and follow an investigation workflow.
