# Module 6: Professional Operations & Projects

**Days 26–30 · Advanced**

You will administer systems remotely and securely, work through realistic network and system investigations, build integrated diagnostic tooling, and complete the final capstone and examination.

## Module outcomes

- Use SSH keys, SCP/SFTP and PowerShell Remoting (WinRM and SSH) securely.
- Apply a root-cause-analysis methodology to CPU, memory, disk and network problems.
- Build and run full Linux and Windows diagnostic scripts that produce CSV and text reports.
- Demonstrate end-to-end skills in the capstone and final exam.
