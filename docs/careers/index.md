# Career Pathways

Everyone completes the core 30 days. The pathways tell you **which lessons to go deeper on**, which extra exercises to do, and which **final toolkit** to build for your portfolio.

<div class="grid cards" markdown>

-   :material-shield-account:{ .lg .middle } **[Path A — SOC Analyst](soc-analyst.md)**

    ---

    Authentication monitoring, Windows Security events, process and connection investigation, firewall auditing, security reporting.

    **Final project:** Security Investigation Toolkit

-   :material-lan-connect:{ .lg .middle } **[Path B — Network Analyst](network-analyst.md)**

    ---

    IP addressing and subnetting, routing, DNS, DHCP, TCP/UDP, packet capture, Wireshark, Nmap, network automation.

    **Final project:** Network Diagnostic Toolkit

-   :material-server-network:{ .lg .middle } **[Path C — System Administrator](sysadmin.md)**

    ---

    Users, files, storage, services, software, backups, logs, maintenance, remote administration and automation.

    **Final project:** System Health Monitoring Toolkit

</div>
