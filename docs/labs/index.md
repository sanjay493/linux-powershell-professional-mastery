# Practical Labs

Every day has a dedicated lab. Each lab includes a **Lab ID, objective, required environment, initial conditions, step-by-step instructions, expected results, verification steps, troubleshooting, questions and a full solution** for Bash and PowerShell.

!!! warning "Before any lab"
    Read [Lab Environment & Safety](../getting-started/lab-environment.md). Labs run only on localhost, WSL2, your own VMs or explicitly authorised systems. Take a snapshot or backup before labs that change configuration.
