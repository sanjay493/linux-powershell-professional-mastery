## How each entry is organised

| Field | Meaning |
|---|---|
| **OS / version** | Where it works (Ubuntu, Windows, PowerShell 5.1 / 7) |
| **Description** | What it does |
| **Syntax** | Formal usage line |
| **Parameters** | The options you will actually use |
| **Example** | A realistic command |
| **Expected output** | What a typical result looks like (example; values differ per system) |
| **Equivalent** | The closest command on the other platform |
| **Common errors** | Errors you are likely to hit and why |
| **Use case** | A real professional situation |
| **Docs** | Official documentation link |
