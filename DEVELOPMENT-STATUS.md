## Curriculum topics (reference for nightly releases)

The full topic list for each day is in `docs/course/index.md` (key commands) and in the original specification:

- **Day 03** Reading and managing files: `cat`, `less`, `more`, `head`, `tail` (`-f`, `-n`), `wc`; `Get-Content` (`-TotalCount`, `-Tail`, `-Wait`), `Select-Object`, `Measure-Object`; reading logs; large files; redirection (`>`, `>>`, `2>`, `2>&1`, `&>`, `Out-File`, `Tee-Object`, PowerShell streams 1–6).
- **Day 04** Searching: `find`, `grep` (`-r -i -n -v -E -c -l`), `locate`/`plocate`, `which`; `Get-ChildItem -Recurse -Filter`, `Select-String`, `Where-Object`; wildcards vs regular expressions; multi-file search; practical log searching.
- **Day 05** Help, history, pipelines: `man`, `--help`, `history`, `type`, `command -v`; `Get-Help`, `Get-Command`, `Get-History`, `Get-Alias`; text vs object pipelines; `;` `&&` `||`; exit codes `$?`, `$LASTEXITCODE`, `$?` in PowerShell; basic error handling.
- **Day 06** Users and groups (published 2026-11-09): `/etc/passwd`, `/etc/shadow`, `/etc/group`, `useradd`, `adduser`, `usermod -aG`, `passwd`, `chage`, `userdel`, `gpasswd`; `*-LocalUser`, `*-LocalGroup*`, `net user`; onboarding and offboarding.
- **Day 07** File permissions and access control (published 2026-11-10): `chmod` (numeric and symbolic), `chown`, `chgrp`, `umask`, special bits; `Get-Acl`, `Set-Acl`, `icacls`; NTFS inheritance; back up ACLs before changes.
- **Day 08** Processes and services (published 2026-11-10): `ps`, `top`, `htop`, `kill`, `pgrep`, `systemctl`, `journalctl -u`; `Get-Process`, `Stop-Process`, `Get-Service`, `Restart-Service`; ships `process-monitor` scripts.
- **Day 09** Disk and storage management (published 2026-11-11): `df`, `du`, `lsblk`, `blkid`, `findmnt`, `mount`, fstab, inodes, `lsof +L1`, LVM; `Get-PSDrive`, `Get-Volume`, `Get-Disk`, `Get-Partition`, `Win32_LogicalDisk`; ships `disk-monitor` scripts.
- **Day 10** Software and package management (published 2026-11-11): `apt`, `dpkg`, `apt-mark`, snap, `dnf`/`rpm`; `winget`, Uninstall registry inventory, `Get-HotFix`, PowerShellGet/PSResourceGet; ships the Module 2 test.
- **Day 11** IP configuration (published 2026-11-12): `ip addr/link/route/neigh`, `ip route get`, subnetting, APIPA, netplan, `nmcli`; `Get-NetIPConfiguration`, `Get-NetIPAddress`, `Get-NetRoute`, `Find-NetRoute`, `Get-NetNeighbor`, `New-NetIPAddress`, `ipconfig`.
- **Day 12** Connectivity troubleshooting (published 2026-11-12): layered method, `ping`, `traceroute`, `tracepath`, `mtr`, path MTU, `nc -zv`, `curl`; `Test-Connection` (5.1 vs 7), `Test-NetConnection`, `tracert`, `pathping`.
- **Days 13–30:** as listed in `docs/course/index.md` and the course specification sections for Modules 3–6. Day 13 (DNS) can build on the Lab 12 namespace topology; Day 15 should go deeper on `ip link`/`ip neigh`/`Get-NetAdapter` than Day 11 did.
